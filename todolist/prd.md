# TODO List 제품 요구사항 문서 (PRD)

## 1. 제품 개요

HTML5, CSS3, 순수 JavaScript로 만드는 개인용 할 일 관리 웹사이트다. 사용자는 할 일을 빠르게 등록하고 완료 여부와 목록 상태를 관리할 수 있다. 데이터는 현재 브라우저에 저장하며 계정이나 서버는 사용하지 않는다.

## 2. 목표 및 범위

### 목표

- 별도의 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있다.
- 할 일 추가, 수정, 완료 처리, 삭제를 직관적으로 제공한다.
- 새로고침 후에도 브라우저에 저장된 할 일 목록을 복원한다.
- 데스크톱과 모바일 화면에서 모두 사용하기 편하다.

### MVP 범위

- 할 일 추가, 내용 수정, 완료/미완료 전환, 개별 삭제
- 전체/진행 중/완료 항목 필터
- 완료 항목 전체 삭제
- 할 일 개수와 빈 목록 상태 표시
- `localStorage`를 이용한 브라우저 내 데이터 저장
- 반응형 레이아웃과 키보드 조작 지원

### 범위 제외

- 사용자 계정, 로그인, 서버 동기화
- 여러 기기 간 데이터 공유 및 협업
- 마감일, 우선순위, 카테고리, 알림
- 백엔드 API 및 데이터베이스

## 3. 사용자 및 사용 시나리오

주 사용자는 개인 일정이나 일상적인 작업을 간단히 기록하고 관리하려는 사람이다.

1. 사용자가 입력란에 할 일을 입력하고 추가한다.
2. 사용자가 체크 컨트롤을 선택해 항목을 완료하거나 다시 진행 중으로 되돌린다.
3. 사용자가 항목 내용을 수정하거나 더 이상 필요 없는 항목을 삭제한다.
4. 사용자가 필터를 바꿔 전체, 진행 중, 완료 항목을 확인한다.
5. 사용자가 페이지를 다시 열거나 새로고침해도 이전 목록을 확인한다.

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 사용자는 비어 있지 않은 할 일을 추가할 수 있다. 앞뒤 공백은 제거하며 빈 입력은 추가하지 않는다. | 필수 |
| FR-02 | 새 할 일은 미완료 상태로 목록에 표시된다. | 필수 |
| FR-03 | 사용자는 할 일의 완료/미완료 상태를 전환할 수 있다. | 필수 |
| FR-04 | 사용자는 기존 할 일의 내용을 수정하고 저장하거나 취소할 수 있다. | 필수 |
| FR-05 | 사용자는 할 일을 개별 삭제할 수 있다. | 필수 |
| FR-06 | 사용자는 전체, 진행 중, 완료 필터로 목록을 전환할 수 있다. | 필수 |
| FR-07 | 사용자는 완료된 할 일을 한 번에 삭제할 수 있다. 완료 항목이 없으면 이 동작은 비활성화하거나 숨긴다. | 권장 |
| FR-08 | 화면은 남은 진행 중 할 일의 개수를 표시한다. | 권장 |
| FR-09 | 목록이 비었거나 선택한 필터에 표시할 항목이 없을 때 안내 상태를 표시한다. | 권장 |
| FR-10 | 변경된 목록은 브라우저 저장소에 반영되고, 재방문 시 복원된다. | 필수 |

## 5. 비기능 요구사항

- 추가 라이브러리나 프레임워크 없이 HTML5, CSS3, JavaScript로 동작한다.
- 주요 기능은 마우스뿐 아니라 키보드로도 조작할 수 있다.
- 입력 요소와 버튼은 목적을 알 수 있는 레이블 또는 접근 가능한 이름을 제공한다.
- 화면 폭이 좁은 모바일에서도 콘텐츠가 가로로 넘치지 않는다.
- 사용자 입력을 HTML로 직접 해석하지 않고 텍스트로 표시한다.
- 저장 데이터가 없거나 형식이 유효하지 않은 경우 앱이 중단되지 않고 빈 목록으로 시작한다.

## 6. 사용자 인터페이스 요구사항

- 페이지 제목과 새 할 일 입력 영역
- 할 일 목록 및 각 항목의 완료 컨트롤, 수정/삭제 동작
- 전체/진행 중/완료 필터
- 남은 할 일 수 및 완료 항목 전체 삭제 동작
- 현재 목록 상태에 맞는 빈 상태 안내
- 모바일과 데스크톱에 대응하는 간결한 단일 페이지 레이아웃

## 7. 완료 기준

- 필수 기능 요구사항(FR-01~FR-06, FR-10)을 모두 만족한다.
- 추가/수정/완료/삭제/필터 동작이 서로 일관되며 화면에 즉시 반영된다.
- 새로고침 후 저장된 목록이 복원된다.
- 빈 입력, 저장 데이터 없음, 손상된 저장 데이터에서도 화면이 정상적으로 표시된다.
- 데스크톱 및 모바일 폭에서 핵심 UI를 사용할 수 있다.
- 키보드로 입력, 완료, 수정, 삭제 및 필터 조작이 가능하다.
