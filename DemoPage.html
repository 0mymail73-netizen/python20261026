웹 기초 실습 페이지

HTML5로 구조를 만들고, CSS3로 꾸미고, JavaScript로 움직여 보세요.

HTML5

1. 페이지의 구조 만들기

HTML은 웹페이지의 내용과 의미를 표현합니다. <header>, <main>, <section>, <footer>처럼 의미가 분명한 태그를 사용하면 구조를 이해하기 쉬워집니다. 

<main>
  <section>
    <h2>소개</h2>
    <p>여기에 내용을 작성합니다.</p>
  </section>
</main>
CSS3

2. CSS로 모양과 배치 꾸미기

CSS는 색상, 글꼴, 간격, 배치 등 화면에 보이는 모습을 정합니다. 이 페이지의 카드와 버튼에도 CSS가 적용되어 있습니다. 

.card {
  padding: 1rem;
  border-radius: 12px;
  background: white;
}
JavaScript

3. JavaScript로 동작 추가하기

버튼을 눌러 횟수를 올리거나 화면 테마를 바꿔 보세요.

버튼을 누른 횟수: 0

버튼을 눌러 실습해 보세요.

const button = document.querySelector("#count-button");
button.addEventListener("click", () => {
  // 버튼을 눌렀을 때 실행할 코드를 작성합니다.
});
HTML, CSS, JavaScript를 직접 수정하며 결과를 확인해 보세요.
